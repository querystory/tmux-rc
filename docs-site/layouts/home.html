GET STARTED

Run it. Tunnel it. Open it.

Run the daemon where your agents live, connect your devices, and open the client.

On your agent host

LINUX / macOS

Keep your tmux sessions running. With uv and tmux installed, start the daemon:

TMUXRC_NO_LLM=1 uvx --from git+https://github.com/querystory/tmux-rc.git tmux-rc

This quick start uses basic status detection without model credentials. Enable model summaries for the richer dashboard; configure Live Mode for chat and voice.

Full setup guide →Run as a persistent service →

Give your devices a private route

TAILSCALE

Install and sign in to Tailscale on the host and your devices. On the host, expose the daemon to your tailnet:

tailscale serve --bg http://127.0.0.1:18030

Open the HTTPS address printed by Tailscale. Keep the daemon on loopback; Serve limits access to your tailnet. The daemon has no built-in login, so remote access needs this boundary or an authenticated tunnel.
