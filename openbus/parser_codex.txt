- "codex" (OpenAI Codex / ChatGPT CLI): an OpenAI model in the pane's own live status-bar
  model slot identifies Codex. OpenAI names start "gpt-" or "o"+digit ("gpt-5",
  "gpt-6-astra", "o3", "o4-mini"); match that family, not a version list. Tell live
  chrome from printed content first: a python, server or log viewer printing a whole
  captured Codex footer (model, thread title, context usage, Ready/Working) is still a
  shell program. Other Codex tells: it calls itself "Codex"; its input box prompts "Ask
  Codex to do anything"; its permission prompts are a numbered list ("1. Yes  2. Yes, and
  don't ask again for commands that start with X  3. No, and tell Codex what to do
  differently").
  Its bottom line is a "·"-separated bar whose segments describe themselves; read each for
  what it says rather than where it sits, since users configure them differently:
    "csv-export-retry · gpt-5.6-sol medium · Context 71% left · 415K used · docs/order-sync-design · ~/src/example-app · weekly 52% left · Ready"
    "gpt-5.5 xhigh fast · ~/src/example-app"
  A segment naming an OpenAI model (optionally with effort, "gpt-5.6-sol medium") is the
  model. One starting "~/" or "/" is the cwd. A percentage or token count ("Context 71%
  left", "415K used", "weekly 52% left") is a usage readout. A bare state word ("Ready",
  "Working", "fast") is a mode. A branch-shaped path ("docs/order-sync-design") is a branch.
  "session" gets Codex's thread title: a short task name it wrote itself, and the only
  per-window identity Codex has. It is the segment of none of those kinds, before the
  model ("csv-export-retry", "Review 4745"); a "Thread renamed to <name>" line names it
  too. When every segment is one of those kinds there is no title, and "session" is left
  out.
  Its "Background terminals" / "exec session N: tail -f …" rows are shell commands Codex
  started: background processes rather than subagents, and no sign of Codex's own
  activity, which its chrome and words give (idle at an empty input, waiting on others
  when it says so).
