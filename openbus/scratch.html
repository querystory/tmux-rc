Scratch is where coding agents publish previews for you: HTML pages, Markdown documents, mocks, reports, charts and images. Each lands in a folder of its own and shows up here as a card, with who made it.

The daemon serves the folder named by TMUXRC_SCRATCH_DIR in its .env. With TMUXRC_SCRATCH_ADVERTISE=1 and TMUXRC_SCRATCH_URL (this page's address), new panes learn where it is. Then add this to your agents' instructions, such as AGENTS.md or CLAUDE.md:

If TMUXRC_SCRATCH_DIR is set, you can show the user a preview (an HTML page, a Markdown document, a built static site, a report, images, a PDF). Write it into a new subfolder as index.md (Markdown, with Mermaid diagrams, admonitions, task lists and tables) or index.html, for example $TMUXRC_SCRATCH_DIR/<folder>/index.md, and give the user $TMUXRC_SCRATCH_URL/<folder>/ (or the folder's path if that variable is unset). The public URL sits behind the user's login, so to check the page yourself request $TMUXRC_SCRATCH_LOCAL_URL/<folder>/ instead; exactly 200 means it is served (a 202 is a page still being made). Everything in that directory is visible to everyone who can reach tmux-rc: never put secrets or private data there. Pages are sandboxed: their scripts cannot fetch, use XHR or WebSockets, or submit forms, so inline any data a page needs. Write the folder's meta.json ({"title", "description", "pane": "$TMUX_PANE", "created": ISO 8601 time}) first, before the page: until index.html or index.md lands, the link shows that the page is being made, so it is safe to hand out early, and the user is notified when it is ready.
